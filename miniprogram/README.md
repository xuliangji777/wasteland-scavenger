## 二、在微信开发者工具中运行（个人 AppID，零域名配置）

### 第 1 步：准备个人小程序 AppID
1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册**个人主体**微信小程序（免费、无需营业执照）。
2. 登录后台 → **开发管理** → **开发设置**，复制你的 `AppID(小程序ID)`。
   > 如仅做本地预览，也可先使用 `touristappid`（游客模式），或点击「测试号」体验。

### 第 2 步：导入项目
1. 打开 **微信开发者工具**（建议使用最新稳定版，基础库选择 **2.30.0 及以上** 以完整支持 Canvas 2D）。
2. 点击 **导入项目**：
   - **项目目录**：选择本仓库下的 `miniprogram/` 目录（注意不是仓库根目录，而是 `miniprogram` 文件夹）。
   - **AppID**：填入你的个人小程序 AppID。
   - **后端服务**：选择 **不使用云服务**。
3. 点击 **导入**，等待编译完成。

### 第 3 步：横屏模拟与真机预览
1. **模拟器横屏**：在开发者工具顶部模拟器工具栏点击 **旋转屏幕**（切换为横屏，如 `iPhone 14 Pro 横屏` 或 `844×390`），即可呈现完整 1080P 无框水墨宽屏视界与左下角挖孔屏安全区十字键。
2. **真机调试**：点击工具栏 **预览** 或 **真机调试**，用微信扫码即可在手机上全屏横屏游玩，支持原生触控震动反馈（`wx.vibrateShort`）与离线本地三档存档。

> **无需配置业务域名 / 服务器域名！**  
> 本版本完全不依赖 `web-view`，也不发起任何外部 `wx.request` 网络请求，所有游戏逻辑、五域 21 张地图、27 条墨壶配方、16 项四系武学及三档存档均运行在微信客户端本地。

## 三、提交微信审核上线指引

1. **检查包体大小**：点击开发者工具右侧 **详情** → **代码依赖分析**，确认主包、分包 `pkg_game`、`pkg_maps` 各自均小于 `2MB`（总包约 `3MB`，远低于 20MB 上限）。
2. **关闭不校验域名（可选）**：因无任何外部请求，保持默认安全校验即可通过。
3. **点击上传**：在工具栏点击 **上传**，填写版本号（如 `1.0.0`）与备注（如 `《墨土拾荒录》v20 纯原生水墨RPG首版`）。
4. **公众平台提审**：
   - 登录 [微信公众平台](https://mp.weixin.qq.com/) → **版本管理** → 找到刚上传的开发版本 → 点击 **提交审核**。
   - 个人主体建议类目：**娱乐 / 休闲益智** 或按平台提示选择适配类目（纯单机无充值、无用户生成内容、无外部链接，过审极快）。
   - 审核通过后点击 **发布**，即可生成小程序码分享给微信好友畅玩！
