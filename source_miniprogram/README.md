# 末世拾荒 · 微信小游戏

> 版本记录：v1.0.0（2026-10-20 初版落地，从外部会话导入全量代码并修复 2 处运行时缺陷）

## 一、项目定位

末世生存题材的放置/经营混合型小游戏：玩家在废土中拾荒、变卖、拆解，积累资源解锁区域，最终触发 4 种结局之一。核心设计理念为「高风险 = 高回报」博弈与「以终为始」的结局驱动。

## 二、技术栈

- 原生微信小程序（WXML + WXSS + JavaScript）
- 纯前端本地存储（`wx.setStorageSync`），无后端、无云服务依赖
- 开发工具：微信开发者工具（个人主体，测试号即可跑通）

## 三、目录结构

## 四、玩法系统清单

| 模块 | 内容 |
|---|---|
| 核心循环 | 拾取 / 出售 / 拆解；体力+饱食度双消耗，每 3 秒自然恢复/衰减 |
| 品质系统 | 普通 / 优良 / 稀有 / 传说 4 档，影响售价倍率（1 / 1.5 / 3 / 10） |
| 地图 | 城郊废土堆（初始）、废弃居民楼（800 金）、军工厂废墟（2500 金）、辐射沼泽（6000 金） |
| 地图机制 | 居民楼：警戒值满触发掠夺者追捕；军工厂：化学品溅射额外扣体力；沼泽：60 秒周期辐射潮，按背包价值 40% 损失 |
| 结局（4种） | ① 庇护之地（金≥15000）② 同伴重逢（集齐 5 件信物）③ 末世收藏家（集齐 6 件古董）④ 隐藏·废土之王（古董+信物+全地图+拾荒 500 次） |
| 运营系统 | 每日任务 ×3、周常任务、本地排行榜（Top10）、好友协作悬赏（分享助力，每日刷新） |
| 配套系统 | NPC 对话（商人/哨兵/隐士）、高利贷（日息 20%，出售自动扣还）、隐藏密室（手电提升发现率）、天气（晴天/辐射尘，影响稀有率与体力消耗）、技能树 ×6、战前古董图鉴、随机事件 ×4 |

## 五、运行步骤

1. 微信开发者工具 → 新建项目 → 选择本目录 → AppID 可用测试号
2. 点击「编译」，模拟器即可运行；真机预览需正式账号
3. 正式发布：个人主体注册 + ICP 备案 + 软著（可用电子版权认证替代）；纯广告变现（IAA）免版号

## 六、已知修复记录（v1.0.0）

1. **随机事件崩溃**：回调函数原经 `setData({eventCB: fn})` 传递会被序列化丢弃，导致事件选项点击即报错 → 改用实例属性 `this._eventCB` 存储
2. **定时器泄漏**：`restartGame` 直接调用 `onLoad()` 会重复创建状态循环与辐射潮两组 `setInterval` → 句柄存入 `this._statusTimer / this._tideTimer`，重开前先 `clearInterval`
